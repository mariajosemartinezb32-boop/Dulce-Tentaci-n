## 🚀 Despliegue en GitHub Pages (Paso a Paso)

Este repositorio incluye el flujo automatizado de *GitHub Actions* (`.github/workflows/deploy.yml`) para un despliegue inatenterrumpido.

### Opción 1: GitHub Actions (Automático - Recomendado)
1. Sube este codigo a tu repositorio en GitHub (rama `main` o `master`).
2. En tu repositorio, ve a *Settings* > *Pages*.
3. En *Build and deployment* > *Source*, selecciona *GitHub Actions*.
4. GitHub desplegará tu web automáticamente. 

### Opción 2: Deploy from a branch (Clásico)
1. En *Settings* > *Pages*.
2. En *Source*, elije *Deploy from a branch*.
3. Selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Guarda los cambios. Tu sitio estará activo en `github.io`.
